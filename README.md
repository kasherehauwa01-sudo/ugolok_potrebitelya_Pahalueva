# Уголок потребителя — Любо маркет

Статическая страница ИП Пахалуевой Любови Николаевны. Структура соответствует уголку потребителя ШопСовет из предоставленного образца. Логотип и регистрационные документы взяты из вложений; реквизиты — из карты партнёра.

## Локальный запуск

Из каталога репозитория:

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

Сборка и установка зависимостей не нужны. Для GitHub Pages можно использовать публикацию из корня ветки с файлами `index.html`, `style.css` и `assets/`.

Режим работы не указан в исходных данных и не добавлен на страницу.
